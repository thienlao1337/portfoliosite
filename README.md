# Relay.build — portfolio page

**Live:** https://thienlao1337.github.io/portfoliosite/

A single-page portfolio site built with plain HTML, CSS and JavaScript — no frameworks, no build step.

## Features

- Responsive layout (desktop and mobile)
- Light and dark theme: follows the system setting, with a manual toggle
- English / Ukrainian language switch; picks the visitor's browser language and remembers their choice
- Accessible: keyboard focus styles, `aria` attributes, respects `prefers-reduced-motion`

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server
```
